PROJECT OVERVIEW

언어 장벽을
경험의 연결로 바꾸다

Problem

여행자는 텍스트가 아닌 맥락을 원한다

낯선 타지의 메뉴판, 복잡한 표지판 앞에서 단순한 직역은 충분하지 않습니다. 여행자에게 진짜 필요한 것은 그 텍스트가 가진 '실제 의미'와 '상황에 맞는 정보'입니다.

  • 모호한 단어의 상황별 오역
  • 음식 재료 등 상세 정보 부재
  • 현지 에티켓 및 문화 정보 부족
Solution

Snap & Solve: 시각적 이해와 언어 가이드

이미지를 촬영하는 순간 Gemini AI가 주변 상황을 함께 분석합니다. 메뉴의 재료 설명부터 거리 표지판의 방향까지, 단순 번역을 넘어 현지 경험을 확장합니다.

OUR MOTIVATION

PicLingo의
제작 배경

해외여행 중 낯선 간판이나 복잡한 메뉴판 앞에서 당황한 적이 있으신가요? 모르는 글자를 번역기에 직접 타이핑하는 것은 너무 번거롭고 시간이 오래 걸립니다. 시중에 사진 번역 앱들이 있지만, 대부분 유료 결제를 유도하여 접근성이 떨어졌습니다.

우리는 누구나 비용 부담 없이, 사진 한 장만으로 언어의 장벽을 허물 수 있도록 PicLingo를 기획했습니다.

USER EXPERIENCE FLOW

복잡함은 빼고,
정답만 남기다

01

지능형 Snap & Solve

단순 OCR을 넘어 이미지 속 객체와 상황을 인식합니다. 메뉴판을 찍으면 음식 이름뿐만 아니라 어떤 재료가 들어갔는지 설명해줍니다.

02

Survival Phrases

교통, 음식, 쇼핑 등 상황별로 정리된 필수 회화 리스트를 제공합니다. 현지 발음과 팁까지 포함되어 당황하지 않고 대화할 수 있습니다.

03

Saved Images & Categories

번역된 이미지들은 음식, 표지판 등으로 자동 분류되어 저장됩니다. 나중에 다시 찾을 때 카테고리 필터를 통해 빠르게 검색할 수 있습니다.

DESIGN PHILOSOPHY & UI/UX INTERACTION STRATEGY

직관적인 흐름과
의도된 인터랙션

Hover / Active

Micro-Interactions

버튼 Active 상태 시 미세한 Scale Transform 적용. 주요 정보 Hover 시 Opacity 조절을 통한 강조로 사용자의 심리적 안정감을 제공합니다.

Transition / Transform

Easing Flow

모달 팝업 및 화면 전환 시 부드러운 맞춤형 이징 함수를 사용. Z-index Depth 활용으로 깊이감 있는 레이어 배치를 구현했습니다.

Flex / Grid

Mobile-First Layout

CSS Flex 박스와 Grid 시스템으로 모바일에 최적화된 반응형 UI 구현. 전 기기 UI 일관성을 확보했습니다.

Keyframes / Animation

AI Loading State

@keyframes 기반 순차 애니메이션으로 AI 분석 중임을 직관적으로 표시. 체감 대기 시간을 최소화했습니다.

Palette

Vibrant Yellow Identity

여행의 즐거움과 에너지를 상징하는 #FFD700 컬러를 포인트로 활용하여 밝고 직관적인 브랜드 아이덴티티를 구축했습니다.

Structure

Travel-Focused UX

한 손 조작이 잦은 여행 상황을 고려하여 주요 기능(카메라, 번역기)을 엄지손가락 범위 내에 배치하는 Bottom-Nav 구조를 채택했습니다.
